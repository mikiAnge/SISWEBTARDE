# Netflix Clone CRUD

Sistema de gestión de programas televisivos con interfaz estilo Netflix.

## Requisitos

- PHP 7.0 o superior
- MySQL
- Servidor web (Apache/Nginx)
- Extensión PDO de PHP

## Instalación

1. Clonar el repositorio
2. Importar la base de datos desde el archivo SQL proporcionado
3. Configurar la conexión en data/conexion.php
4. Asegurar permisos de escritura en la carpeta imagenes
5. Acceder mediante el navegador

## Características

- Sistema de autenticación
- CRUD completo de programas
- Interfaz estilo Netflix
- Gestión de imágenes
- Diseño responsive
